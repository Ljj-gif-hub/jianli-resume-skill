## 项目经历

### 云端笔记同步服务（2025.06 - 2026.06）
技术栈：Spring Boot 3.2 · MySQL · Redis · Docker
面向个人用户的笔记多端同步服务，独立完成后端全部接口与部署。

- **接口层**：实现 28 个 REST 接口，覆盖笔记增删改查、回收站与标签体系。
- **同步冲突**：用版本号 + 时间戳做冲突合并，解决 3 端并发编辑互相覆盖的问题。
- **性能优化**：热点列表 Redis 缓存 + 增量拉取，接口平均耗时从 380ms 降到 90ms。
- **鉴权安全**：JWT 登录态 + 每分钟 60 次接口限流，拦住越权访问与批量爬取。
- **部署运维**：Docker Compose 一键部署，写备份脚本做数据库每日快照。
- **测试保障**：JUnit 5 单测 60+ 用例覆盖核心服务，回归全绿。
